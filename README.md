# Jothishri B — Portfolio

Personal portfolio for **Jothishri B, Frontend Developer (Chennai, India)** — designed like a
real-time robot-operations dashboard crossed with a polished product site. The site itself is the
proof of skill: a well-built React 19 + TypeScript app with dark/light themes and case-study
routing.

## Plan → file structure

```
Portfolio/
├── index.html                  # SEO, Open Graph, fonts, JSON-LD
├── netlify.toml / vercel.json  # deploy + SPA rewrites
├── public/
│   ├── favicon.svg / og-card.svg / robots.txt / sitemap.xml / _redirects
│   └── Jothishri-B-Resume.pdf  # generated by scripts/make-resume.mjs
├── scripts/make-resume.mjs     # one-page resume PDF generator
└── src/
    ├── main.tsx / App.tsx      # entry, lazy routes, skip link, header/footer
    ├── index.css               # Tailwind v4 + design tokens (CSS vars, dark/light)
    ├── store/useStore.ts       # Zustand: theme (persisted) + project filter
    ├── data/                   # projects.ts, experience.ts, skills.ts (typed content)
    ├── hooks/                  # usePrefersReducedMotion
    ├── components/             # Card, Chip, SectionHeading, ThemeToggle,
    │                           # ProjectCard, ProjectVisual, Reveal,
    │                           # SiteHeader, SiteFooter
    ├── sections/               # Hero, About, Experience, Projects, Skills, Contact
    └── pages/                  # Home, CaseStudy (:slug), Chrome (scroll + 404)
```

## Setup

Requires Node 20+.

```bash
npm install
npm run dev            # http://localhost:5173
```

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Start Vite dev server |
| `npm run build` | `tsc -b` (strict) + production build to `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | oxlint |
| `node scripts/make-resume.mjs` | Regenerate the resume PDF in `public/` |

## Design tokens

All colour/spacing/type tokens live as CSS variables in `src/index.css` (`:root` = light,
`.dark` = dark, the default). Tailwind v4 maps them via `@theme inline`, so classes like
`bg-surface text-muted border-border text-accentink` track the active theme automatically.
One accent colour (teal), Inter for body, JetBrains Mono for data/labels.

## Deployment

**Netlify** — `netlify.toml` is included (`npm run build`, `dist/`, SPA redirect).

**Vercel** — `vercel.json` rewrites all routes to `/index.html`, then `vercel --prod` or
connect the repo.

Before shipping, replace placeholders: canonical/OG domain in `index.html` + `sitemap.xml`,
`contact.linkedin` in `src/data/skills.ts`, `[add real outcome]` strings in
`src/data/projects.ts`, and resume content in `scripts/make-resume.mjs`.

## Accessibility & performance

- Skip link, semantic landmarks, visible focus states, keyboard-navigable menu
- `prefers-reduced-motion` respected (MotionConfig + CSS)
- Routes are lazy-loaded; favicon/OG are inline SVG
